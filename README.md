# EcoLink Dynamics • Landing Page

**Premium, high-conversion marketing website for a pre-MVP climate-tech startup.**

A world-class, futuristic landing page designed to build anticipation, communicate the vision, establish founder credibility, and collect waitlist signups for **EcoLink Dynamics** — the AI-powered platform synchronizing global supply chains for a truly circular economy.

## ✨ Key Features

- **Premium dark futuristic aesthetic** with glassmorphism and emerald glow
- **Fully responsive & mobile-first** design
- **Premium full-screen mobile navigation** (beautiful slide-in menu with large typography)
- **Smooth reveal animations** + scroll progress bar
- **Functional waitlist modal** with simulated success state
- **Founder credibility section** (Adamma Mbajekwe)
- **Clear value proposition**, problem → solution, roadmap, and impact sections
- **Zero build tools** — single HTML file, instantly deployable

---

## 🛠 Tech Stack

- **HTML5** + **Tailwind CSS** (via CDN)
- **Custom CSS** for advanced animations and glass effects
- **Vanilla JavaScript** for interactions
- **Space Grotesk** + **Plus Jakarta Sans** typography
- **Font Awesome 6** icons
- **No frameworks**, no npm, no build step required
